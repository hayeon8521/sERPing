# 프로젝트명 : sERPing

## 개요
기존 ERP 시스템은 높은 비용과 복잡한 기능으로 인해
중소기업과 스타트업이 도입하기 어려운 문제를 해결하기 위해
핵심 기능을 중심으로 저비용·간편형 ERP 시스템을 개발
